# Mercado das Ofertas

**Achadinhos e ofertas reais dos produtos mais vendidos, com compra 100% feita no Mercado Livre.**

O Mercado das Ofertas é uma vitrine que reúne produtos em promoção. Aqui você só escolhe o produto. Toda a compra acontece no site do Mercado Livre, com o pagamento, a entrega e a proteção de lá.

---

## Por que você pode comprar com tranquilidade

### Você não paga nada neste site
O site não tem carrinho, checkout nem campo de pagamento. Quando você clica em **"Comprar no Mercado Livre"**, vai direto para a página oficial do produto no Mercado Livre. É lá que você confere o preço final, escolhe a forma de pagamento e finaliza a compra.

### Seus dados ficam com você
O site **não pede** nome, CPF, e-mail, telefone, endereço ou dados de cartão. Não existe formulário de cadastro e nenhuma informação sua é guardada aqui.

### Proteção da Compra Garantida
Como a compra é feita no Mercado Livre, ela tem a **Compra Garantida** do próprio Mercado Livre: se o produto não chegar ou vier diferente do anúncio, você pode pedir o dinheiro de volta pela sua conta lá.

### Produtos escolhidos com critério
Os produtos da vitrine são selecionados entre os **mais vendidos** do Mercado Livre e seguem estes critérios:

- produto **novo**;
- vendedor com **reputação verde** no Mercado Livre;
- nota dos compradores a partir de **4,5 estrelas**;
- grande volume de vendas.

### Código aberto
O código do site está todo neste repositório. Qualquer pessoa pode conferir que ele não coleta dados e que os botões levam apenas para o Mercado Livre.

---

## Transparência: como o site se mantém

Os links deste site são **links de afiliado** do Programa de Afiliados e Criadores do Mercado Livre. Quando você compra por um desses links, o Mercado das Ofertas recebe uma pequena comissão paga pelo próprio Mercado Livre.

- **Você não paga nada a mais** por isso. O preço é exatamente o mesmo do anúncio.
- A comissão é o que permite manter o site e continuar garimpando ofertas.

O Mercado das Ofertas é uma página independente de divulgação de ofertas. **Não é um site oficial do Mercado Livre** nem tem ligação com a empresa além do programa de afiliados.

---

## Sobre os preços

Os preços e descontos mostrados na vitrine são conferidos na data indicada no site e **podem mudar a qualquer momento**, pois quem define o preço é o vendedor no Mercado Livre. O valor que vale é sempre o que aparece na página do produto no Mercado Livre na hora da compra.

---

## Para quem mantém o site

- O site é uma única página estática (`index.html`), sem servidor nem banco de dados.
- Hospedagem: GitHub Pages (*Settings → Pages → Deploy from branch → main*).
- Para atualizar os produtos, substitua o `index.html` e faça o commit.
